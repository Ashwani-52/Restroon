# Restroon

A Digital Cafe for Local Vendors who don't want to give their 30% commission to others.

Restroon is a comprehensive platform for cafe management, ordering, and delivery. Designed for cafe owners and customers, it features a sleek modern interface right from the browser. 

## Features

* **Cafe Owner Dashboard**: Create and manage menus, see orders in real time, detailed revenue analytics, and manage subscriptions with Razorpay integration.
* **Customer Interface**: Browse nearby cafes, view their rich menus, add items to cart, and place orders directly. Pay securely with Razorpay.
* **Admin Module**: Verify and approve new restaurants, examine platform statistics, and suspend users as needed.
* **Responsive Design**: Mobile-friendly, high-contrast, premium dark mode aesthetic throughout.

## Tech Stack

* **Frontend**: React, Vite, Framer Motion, Tailwind CSS
* **Backend**: Node.js, Express, MongoDB (Mongoose)
* **Payments**: Razorpay

## Installation

1. Clone this repository.
2. In the `server` directory, run `npm install` and add `.env`.
3. Start the node server: `npm run dev`.
4. In the `client` directory, run `npm install` and start Vite: `npm run dev`.
